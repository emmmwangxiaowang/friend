# SoulMate Flutter Skeleton (Phase 1: Week 1-2 Summary)

Overview
- This repository seed provides a standard Flutter project skeleton with a clean, modular structure ready for feature implementation.
- Phase 1 focuses on creating the boilerplate directories, a minimal theming and routing setup, and a README with follow-up steps.

Project structure (initial):
- pubspec.yaml
- lib/
  - main.dart
  - app.dart
  - config/
  - models/
  - services/
  - repositories/
  - blocs/
  - screens/
  - widgets/
- android/
- ios/
- web/

Phase 1 deliverables
- [ ] Create skeleton directory structure and pubspec.yaml draft
- [ ] Implement main.dart, app.dart, and configuration scaffolds (theme.dart, routes.dart)
- [ ] Create basic model/service/repository/bloc shells
- [ ] Add a HomeScreen placeholder and a CustomButton widget
- [ ] Provide a README with setup and next steps

How to proceed (Next steps)
- Run: flutter pub get
- Run: flutter run (on mobile or web) to validate routing and theme basics
- Extend by adding actual features in lib/models, lib/services, lib/repositories, lib/blocs, and lib/screens

Notes
- This is a skeleton intended for Week 1-2 planning and architecture discussion. No business logic is implemented yet.
