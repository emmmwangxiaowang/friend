# Learnings - Spring Skeleton (Phase 1)

- Created a minimal Spring Boot skeleton with Maven build: base layout includes controller, service, repository, entity, dto, config, security, websocket.
- Chosen: Java 17, Spring Boot 3.x, H2 in-memory DB for quick start, and WebSocket support via Spring WebSocket starter.
- Package naming: com.soulmate as a clean, domain-aligned base package.
- Next steps: add more endpoints, expand domain model, wire up real persistence, and implement security per requirements.
